# Imagens Públicas do Projeto

Esta pasta destina-se a armazenar imagens públicas do projeto que serão servidas diretamente na raiz da aplicação.

## Como utilizar

As imagens salvas nesta pasta (`public/images/`) ficam acessíveis publicamente através do caminho `/images/<nome-da-imagem>`.

Exemplo em HTML/JSX:
```jsx
<img src="/images/minha-imagem.jpg" alt="Descrição da imagem" />
```
